Мини-курс Python (в одном файле)

Теория + практика в браузере. 5 тем, каждая с заданием и проверкой.

1. Введение в Python

Python — это язык программирования, который читается почти как английский. Его используют для веб‑сайтов, анализа данных, автоматизации и даже игр.

Программа на Python — это просто список команд. Интерпретатор читает их сверху вниз и выполняет по очереди.

print("Привет, мир!")

Задание

Напиши код, который выводит фразу: Я изучаю Python!

2. Переменные и типы данных

Переменная — это «коробка» с именем, в которой хранится значение. В Python тип определяется автоматически.

name = "Алиса"
age = 25
is_student = True

Можно выводить так:

print(name)
print(age)

Задание

Создай переменные: city = "Москва" и population = 13000000, затем выведи их.

Важно: порядок строк и точные названия переменных имеют значение.

3. Условия (if/else)

Условные конструкции позволяют программе принимать решения. Ключевое слово if проверяет условие, а else срабатывает, если оно ложно.

age = 17
if age >= 18:
    print("Доступ разрешён")
else:
    print("Доступ запрещён")

Задание

Задай переменную score = 85. Если score >= 90, выведи "Отлично", иначе — "Хорошо".

4. Циклы (for / while)

Циклы повторяют действия. for удобно использовать для перебора элементов, while — пока выполняется условие.

for i in range(5):
    print(i)

Задание

Выведи числа от 0 до 4 включительно с помощью цикла for.

5. Функции

Функция — это переиспользуемый блок кода. Объявляется через def, вызывается по имени.

def greet(name):
    return f"Привет, {name}!"

print(greet("Анна"))

Задание

Определи функцию square(x), которая возвращает квадрат числа x. Вызови её для 5 и выведи результат.
